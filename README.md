# Umar Dental Clinic - Official Website

> **Tagline:** "Your Smile is Important to Us"

A premium, modern, professional, and fully responsive website for **Umar Dental Clinic**. Built with a clean medical light theme, patient-focused design, and mobile-first responsiveness.

## ✨ Features

* **Brand Identity**: Features the official Umar Dental Clinic logo preserving original proportions, paired with a welcoming medical color palette (Pure White, Soft Sky Blue, Light Medical Blue, and Navy Blue).
* **Sticky Navigation**: Smooth header with clinic operating hours, direct phone line, and mobile hamburger drawer.
* **Hero Section**: Professional dental care introduction with friendly dentist & patient illustration and trust highlights.
* **About Our Clinic**: Modern clinic interior showcase with patient-first comfort philosophy and strict hygiene standards.
* **Our Dental Services**: Comprehensive service cards with interactive procedure breakdown modals across 9 clinical specialties:
  * General Dentistry
  * Teeth Cleaning & Scaling
  * Teeth Whitening
  * Dental Fillings
  * Root Canal Treatment
  * Tooth Extraction
  * Dental Implants
  * Braces & Orthodontics
  * Cosmetic Dentistry
* **Why Choose Us**: Four core feature pillars focusing on patient care, comfortable environment, modern technology, and personalized plans.
* **Our Doctors**: Professional dentist profiles with editable placeholders for names, degrees, and consultation hours.
* **Smile Gallery**: Interactive Before & After comparison slider with draggable split handle.
* **Patient Testimonials**: Clean review cards with sample placeholders and satisfaction ratings.
* **Appointment Booking**:
  * Real-time client-side form validation.
  * Interactive booking confirmation modal with reference token.
  * Direct 1-click WhatsApp appointment confirmation with pre-filled details.
  * Device Calendar (`.ics`) download.
* **Contact & Directions**: Contact cards, editable address placeholders, Google Maps frame, and instant WhatsApp chat.
* **Mobile Responsiveness**: Thoroughly tested across 320px–480px (mobile), 481px–1024px (tablets), and desktop displays.

## 🚀 Getting Started

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Ahmadyazdani007/umar-dental-clinic.git
   ```
2. Open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox).
3. No build step, Node.js, or external package installation required.
